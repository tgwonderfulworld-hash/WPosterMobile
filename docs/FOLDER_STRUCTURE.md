## Conventions

- **One feature = one folder** under `src/features/`, exposing a barrel `index.ts`
  (`api` for data access, `hooks` for React Query, `components` for feature UI).
- **Path alias** `@/*` → `src/*` (see `tsconfig.json`).
- **Barrels**: import UI from `@/components/ui`, workspace data from
  `@/features/workspace`, i18n from `@/i18n`, theme from `@/theme`.
- **No colors or strings in components** — use `useTheme()` and `useTranslations()`.
- Native folders `android/` and `ios/` are **not committed** (Continuous Native
  Generation — regenerated by `expo prebuild` / `expo run:android`).
